# Substitute this instance's ids into an example query

Substitute this instance's ids into an example query

## Usage

``` r
render_wikibase_query(query, ids)
```

## Arguments

- query:

  the query lines, with Wikidata ids in double braces

- ids:

  a mapping from \[wikibase_local_ids()\]

## Value

the query lines with the local ids substituted
