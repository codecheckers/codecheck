# A reference's type label as HTML, or \`""\` when the type is unknown

For the certificate page's title, which is filled into a Markdown
template rather than a whisker one.

## Usage

``` r
reference_type_html(type_info)
```

## Arguments

- type_info:

  A list with \`type\` and \`agency\`, see \[get_reference_type()\]

## Value

An HTML string
