# Path data for one donut slice

Outer arc clockwise from \`start\` to \`end\`, straight in to the inner
radius, inner arc back again.

## Usage

``` r
donut_slice_path(start, end)
```

## Arguments

- start, end:

  Angles in radians, 0 pointing right, measured clockwise.

## Value

An SVG \`d\` attribute value.
