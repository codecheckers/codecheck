# Every DOI that has a work page: the references and the further references

Every DOI that has a work page: the references and the further
references

## Usage

``` r
all_work_keys(register_table)
```

## Arguments

- register_table:

  The register table, with \`Work\` and, optionally, \`Work other\`
  columns

## Value

A character vector of unique DOIs
