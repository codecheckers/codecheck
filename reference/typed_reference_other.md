# A paper's further references with the type of each, see \[get_reference_type()\]

A paper's further references with the type of each, see
\[get_reference_type()\]

## Usage

``` r
typed_reference_other(config_yml)
```

## Arguments

- config_yml:

  The parsed \`codecheck.yml\`

## Value

The data frame of \[get_reference_other()\] with \`type\` and \`agency\`
columns, \`NA\` for a web address or an unknown type
