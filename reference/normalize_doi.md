# Reduce a DOI, DOI URL or ResearchEquals PID to the bare DOI

Reduce a DOI, DOI URL or ResearchEquals PID to the bare DOI

## Usage

``` r
normalize_doi(x)
```

## Arguments

- x:

  a DOI in any of the forms used across the API ("doi:10.53962/x",
  "https://doi.org/10.53962/x", "10.53962/x")

## Value

the lowercase bare DOI, or NA
