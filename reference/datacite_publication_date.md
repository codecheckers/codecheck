# The date a DataCite record says the work was made public

The date a DataCite record says the work was made public

## Usage

``` r
datacite_publication_date(attributes)
```

## Arguments

- attributes:

  the \`data\$attributes\` of a DataCite DOI response

## Value

the date as "YYYY-MM-DD" or a partial date, or \`NA\`
