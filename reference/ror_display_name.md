# The name a ROR record is displayed under

The name a ROR record is displayed under

## Usage

``` r
ror_display_name(record, fallback = NA_character_)
```

## Arguments

- record:

  A ROR record, or \`NULL\`

- fallback:

  Returned when the record has no display name

## Value

The \`ror_display\` name, or \`fallback\`
