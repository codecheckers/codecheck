# Retrieve repository metadata from the GitLab.com API

Retrieve repository metadata from the GitLab.com API

## Usage

``` r
get_gitlab_project_metadata(repo)
```

## Arguments

- repo:

  the project path, e.g. \`cdchck/Piccolo-2020\`

## Value

the parsed API response, or \`NULL\` if the project could not be
retrieved
