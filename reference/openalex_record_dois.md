# The DOIs of every copy of a work an OpenAlex record lists

The DOIs of every copy of a work an OpenAlex record lists

## Usage

``` r
openalex_record_dois(fields)
```

## Arguments

- fields:

  The value of \[get_openalex_work_fields_cached_result()\]

## Value

Character vector of \`https://doi.org/\` URLs, possibly empty
