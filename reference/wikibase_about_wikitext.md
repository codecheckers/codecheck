# The instance's About page

The wikibase.cloud hosting policy expects the main page or
\`Project:About\` to say what the instance is for, and disqualifies
instances holding data about living people without local rules for it.
This instance holds person items for authors and codecheckers, so the
page says both: what the instance is, and what it does and does not
record about people.

## Usage

``` r
wikibase_about_wikitext(generated_at = Sys.time())
```

## Arguments

- generated_at:

  the timestamp to stamp the page with

## Value

the page's wikitext
