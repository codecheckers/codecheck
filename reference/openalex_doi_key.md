# The comparable form of a DOI, as \[openalex_record_is_work()\] compares them

The comparable form of a DOI, as \[openalex_record_is_work()\] compares
them

## Usage

``` r
openalex_doi_key(x)
```

## Arguments

- x:

  A DOI, as a URL or bare, or \`NA\`

## Value

The bare, lower-case DOI with \`\_\` read as \`/\`, or \`NA\`
