# The instance's Main Page

The front door, and the one page that used to be written by hand - which
is how it came to miss pages generated after it. The list of where to
look is built from \[WIKIBASE_PAGES\], so a page added there is listed
here too.

## Usage

``` r
wikibase_main_wikitext(generated_at = Sys.time())
```

## Arguments

- generated_at:

  the timestamp to stamp the page with

## Value

the page's wikitext
