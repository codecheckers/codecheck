# Add the \`type\` and \`agency\` of each DOI to a data frame of references

Add the \`type\` and \`agency\` of each DOI to a data frame of
references

## Usage

``` r
add_reference_types(refs)
```

## Arguments

- refs:

  A data frame with \`url\` and \`doi\` columns

## Value

\`refs\` with \`type\` and \`agency\` columns
