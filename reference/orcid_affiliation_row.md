# Turn one ORCID affiliation summary into an affiliation row

Turn one ORCID affiliation summary into an affiliation row

## Usage

``` r
orcid_affiliation_row(section, affiliation)
```

## Arguments

- section:

  The record section the summary came from

- affiliation:

  One \`\*-summary\` element of an affiliation group

## Value

A list with \`section\`, \`organization\`, \`ror\`, \`start\` and
\`end\`
