# The ROR of a venue that also has an organisation page

The ROR of a venue that also has an organisation page

## Usage

``` r
venue_organisation_ror(identifiers)
```

## Arguments

- identifiers:

  A venue's parsed identifiers (see \[parse_venue_identifiers()\]).

## Value

The bare ROR id, or \`NA_character\_\` when the venue has no ROR or no
organisation page was rendered for it.
