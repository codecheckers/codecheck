# Build the datavalue for one value, in the shape wbeditentity expects

Build the datavalue for one value, in the shape wbeditentity expects

## Usage

``` r
wikibase_datavalue(datatype, value)
```

## Arguments

- datatype:

  the property's Wikibase datatype

- value:

  the value, already transformed

## Value

a \`datavalue\` list
