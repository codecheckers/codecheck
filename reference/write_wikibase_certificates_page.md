# Write the certificate index onto the instance

Write the certificate index onto the instance

## Usage

``` r
write_wikibase_certificates_page(session, written, certificates)
```

## Arguments

- session:

  a session from \[wikibase_session()\]

- written:

  the table \[load_wikibase_register()\] built

- certificates:

  the certificate rows

## Value

the page title, invisibly
