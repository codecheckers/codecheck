# The QuickStatements 3.0 command that deprecates a redirected identifier

For \[QUICKSTATEMENTS_RANKS\], which takes the rank as an \`R-\` field
and keeps a statement that exists rather than adding it again.

## Usage

``` r
quickstatements_deprecate_redirect(item, property, value)
```

## Arguments

- item:

  the item

- property:

  the identifier property

- value:

  the identifier

## Value

a tab-separated command
