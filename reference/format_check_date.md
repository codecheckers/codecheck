# The check time as shown to readers: the day, never the time

The check time as shown to readers: the day, never the time

## Usage

``` r
format_check_date(x)
```

## Arguments

- x:

  The raw \`check_time\` value from a codecheck.yml

## Value

\`YYYY-MM-DD\`, or NA if \`x\` is missing or unparseable
