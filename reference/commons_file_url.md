# The URL a Wikimedia Commons file is served from

The URL a Wikimedia Commons file is served from

## Usage

``` r
commons_file_url(file, width = 320)
```

## Arguments

- file:

  A Commons file name, e.g. "Zegel Technische Universiteit Delft.svg"

- width:

  The width to render the file at, in pixels

## Value

The Special:FilePath URL
