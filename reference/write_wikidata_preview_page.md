# Write the Wikidata preview onto the instance

Write the Wikidata preview onto the instance

## Usage

``` r
write_wikidata_preview_page(session, preview, certificates, batches)
```

## Arguments

- session:

  a session from \[wikibase_session()\]

- preview:

  the table \[preview_wikidata_export()\] built

- certificates:

  the certificate rows

- batches:

  the QuickStatements batches

## Value

the page title, invisibly
