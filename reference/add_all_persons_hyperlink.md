# Add hyperlinks to the "all persons" overview table

Mirrors \[add_all_codecheckers_hyperlink()\].

## Usage

``` r
add_all_persons_hyperlink(table, table_details = NULL)
```

## Arguments

- table:

  The persons table (see \[create_all_persons_table()\]).

- table_details:

  Unused; kept for signature parity with the other
  \`add_all\_\*\_hyperlink()\` functions
  (\[create_tables_non_register()\] dispatches to all of them the same
  way).

## Value

The data frame with hyperlinks added.
