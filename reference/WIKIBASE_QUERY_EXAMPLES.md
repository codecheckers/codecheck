# Example queries against this instance

Short, and only what Wikidata cannot answer: the codechecker link exists
here and nowhere else, because people are resolved on Wikidata rather
than created there, and the certificates on Wikidata carry no \`author\`
statement.

## Usage

``` r
WIKIBASE_QUERY_EXAMPLES
```

## Details

Entity ids are written as the Wikidata ids the model names, in double
braces, and resolved to this instance's numbers by
\[render_wikibase_query()\].
