# The QuickStatements batches recorded as run on Wikidata

The QuickStatements batches recorded as run on Wikidata

## Usage

``` r
wikidata_submitted_batches(log_file = NULL)
```

## Arguments

- log_file:

  the edit log, or \`NULL\` for the \`codecheck.wikibase_log\` option

## Value

the log rows of the submitted Wikidata batches, oldest first
