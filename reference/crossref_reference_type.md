# The type label of a Crossref record

Crossref types a preprint as posted content of subtype preprint, which
is what a bioRxiv, medRxiv or OSF preprint is.

## Usage

``` r
crossref_reference_type(message)
```

## Arguments

- message:

  The \`message\` of a Crossref works response

## Value

A display label, or \`NA\` for a type not shown on the register
