# The instance's Copyrights page

The hosting policy requires the licensing statement to be visible on
\`Project:Copyrights\`. The register's data is under ODC-BY rather than
CC0, so the page states that rather than asserting a waiver nobody has
granted, and says why the individual statements are nonetheless freely
reusable.

## Usage

``` r
wikibase_copyright_wikitext(generated_at = Sys.time())
```

## Arguments

- generated_at:

  the timestamp to stamp the page with

## Value

the page's wikitext
