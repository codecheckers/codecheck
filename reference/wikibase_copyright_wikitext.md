# The instance's Copyrights page

The hosting policy requires the licensing statement to be visible on
\`Project:Copyrights\`, and requires the structured data to be in the
public domain or under CC0. The register's data is dedicated to the
public domain under CC0 1.0 (codecheckers/register#225), and the page
says so. The policy also requires a licence for the text in all other
namespaces that permits commercial use and derivatives; that text is CC
BY 4.0.

## Usage

``` r
wikibase_copyright_wikitext(generated_at = Sys.time())
```

## Arguments

- generated_at:

  the timestamp to stamp the page with

## Value

the page's wikitext
