# Add hyperlinks to the "all organisations" overview table

Mirrors \[add_all_persons_hyperlink()\].

## Usage

``` r
add_all_organisations_hyperlink(table, table_details = NULL)
```

## Arguments

- table:

  The organisations table (see \[create_all_organisations_table()\]).

- table_details:

  Unused; kept for signature parity with the other
  \`add_all\_\*\_hyperlink()\` functions.

## Value

The data frame with hyperlinks added.
