# Download the Font Files of a Library

Download the Font Files of a Library

## Usage

``` r
download_library_fonts(libs_dir, lib, force = FALSE)
```

## Arguments

- libs_dir:

  Base libraries directory

- lib:

  Library specification with a \`fonts\` entry

- force:

  If TRUE, re-download fonts even if they already exist

## Value

\`TRUE\` if at least one font file was downloaded
