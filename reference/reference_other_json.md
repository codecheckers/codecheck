# A certificate's further references for its \`index.json\`

A certificate's further references for its \`index.json\`

## Usage

``` r
reference_other_json(refs)
```

## Arguments

- refs:

  The further references with their types, see
  \[typed_reference_other()\]

## Value

A list of lists with \`url\` and, where known, \`doi\` and \`type\`;
empty without further references
