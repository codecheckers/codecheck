# Rows of one kind from two tables, each filled up with the other's columns

Rows of one kind from two tables, each filled up with the other's
columns

## Usage

``` r
bind_export_rows(rows, extra)
```

## Arguments

- rows:

  a \`data.frame\` of export rows

- extra:

  a \`data.frame\` of more rows, or \`NULL\`

## Value

\`rows\` and \`extra\`, bound, as a \`data.frame\`
