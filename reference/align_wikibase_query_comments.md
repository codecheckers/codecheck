# Line up the comments in a query

A placeholder is longer than the local id it becomes, so comments
written straight in the model come out ragged once substituted. They are
the labels that make an unfamiliar property number readable, so they are
aligned here rather than by hand.

## Usage

``` r
align_wikibase_query_comments(query)
```

## Arguments

- query:

  the query lines

## Value

the lines with their comments aligned
