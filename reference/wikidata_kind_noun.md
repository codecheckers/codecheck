# What an entity kind is called outside the model

The model's \`paper\` kind is a checked \*work\*, which is what the
register, the certificates and every message here call it. Anything a
person reads or types - a batch file name, a count in a warning - uses
this rather than the kind.

## Usage

``` r
wikidata_kind_noun(kind)
```

## Arguments

- kind:

  an entity kind

## Value

the noun, singular
