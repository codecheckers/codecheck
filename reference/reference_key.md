# What makes two references the same: the DOI, in any spelling, or else the address as written

Shared by rendering (\[get_reference_other()\]) and rule \`CC-CFG-033\`,
so that both count the same entries as repeats.

## Usage

``` r
reference_key(x)
```

## Arguments

- x:

  Character vector of references

## Value

The lowercased bare DOI of each, or the trimmed reference
