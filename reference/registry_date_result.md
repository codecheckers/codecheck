# The publication date in a registry record lookup, as a date lookup result

The publication date in a registry record lookup, as a date lookup
result

## Usage

``` r
registry_date_result(record)
```

## Arguments

- record:

  A result of \[get_registry_record_result()\]

## Value

A list with \`status\` and \`value\`, see
\[get_registry_publication_date_result()\]
