# Retrieve the rendered README of a GitHub repository, as raw text

Retrieve the rendered README of a GitHub repository, as raw text

## Usage

``` r
get_github_readme_raw(repo)
```

## Arguments

- repo:

  the \`org/repo\` or \`org/repo\|path\` spec

## Value

the README text, or \`NULL\` if none was found
