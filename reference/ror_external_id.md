# One of a ROR record's external identifiers

One of a ROR record's external identifiers

## Usage

``` r
ror_external_id(record, type)
```

## Arguments

- record:

  A ROR record, or \`NULL\`

- type:

  The identifier type, e.g. "wikidata" or "grid"

## Value

The preferred value, or the first one, or \`NA_character\_\`
